# XP Storage

Forge mod for Minecraft 1.20.1. The prototype adds an XP Containment Capsule that stores experience points in its block entity and persists them through world saves.

## Development
- Minecraft 1.20.1
- Forge 47.4.0
- Java 17
- Mod ID: `xpstorage`

## Current prototype
- Place the XP Containment Capsule.
- Right-click it to deposit all current experience points.
- Stored experience is saved in block entity NBT.

The current block model is a temporary placeholder. The laboratory capsule model, animated liquid, integrated computer interface, withdrawal system, and transfer particles are planned next.
